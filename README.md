# 💰 Investment Growth Calculator

## 📘 Introduction  
This project is a web-based investment growth calculator built using Dash and Plotly. It allows users to input initial capital, monthly investment, expected annual return, and investment duration to visualize how their wealth grows over time.

## 🛠 Backgrounds  
The goal of this project was to create an interactive and educational tool that demonstrates the impact of consistent investing and compound interest. It serves as a personal finance resource to help users make more informed investment decisions.

## 🧰 Tools used  
- **Python** – core programming language  
- **Dash** – for building interactive web applications  
- **Plotly** – for creating rich, interactive graphs  
- **Pandas** – for data manipulation and structure  
- **HTML/CSS** (within Dash) – for styling the layout

## 📊 Analysis  
The app calculates compound interest growth monthly based on user-defined inputs. It separates invested capital from interest gains, providing a clear picture of how much of the final amount is due to investment contributions versus interest. The user can also toggle between linear and logarithmic scales to better understand exponential growth.

## 📚 What I learned  
- How to build and style a responsive dashboard using Dash  
- Implementing callback functions to make apps reactive to user input  
- Applying compound interest formulas in a real-world context  
- Structuring data effectively with Pandas for plotting

## 🔎 Insights  
- Small monthly investments can significantly impact total wealth over long periods, especially with higher annual returns.  
- The difference between total value and invested capital highlights the power of compound interest.  
- Logarithmic scale can be useful for visualizing exponential growth patterns that are less apparent on a linear scale.

## 🏁 Conclusion  
This project demonstrates the value of long-term investing and how simple inputs can be transformed into actionable insights through data visualization. It’s a practical tool for anyone interested in understanding personal finance, and a great example of combining Python with data visualization for real-world applications.
